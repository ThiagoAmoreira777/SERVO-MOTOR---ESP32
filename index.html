esp32_servo.h

Uma biblioteca simples em linguagem C para controle de servos no ESP32, criada porque era difícil encontrar algo direto ao ponto usando ESP-IDF puro — sem Arduino, sem dependências extras.

LEDC / PWM ESP-IDF 0–180° Multi-servo ADC + Potenciômetro

// objetivo

Por que essa biblioteca?

Ao estudar o ESP32 com ESP-IDF, percebei que a grande maioria dos exemplos de servo motor disponíveis usa o framework Arduino. Bibliotecas em C puro, direto com a API do ESP-IDF, são raras e pouco documentadas. Esse projeto nasceu da necessidade de ter algo simples, direto e funcional para quem quer trabalhar com servos sem depender do Arduino.

Como usar

Inclua os arquivos no seu projeto e chame as funções:

main.c 
#include "servo.h"
#include "driver/adc.h"

#define POTENCIOMETRO  ADC1_CHANNEL_6  // GPIO 34
#define SERVO_PINO     18

void app_main(void) {
    adc1_config_width(ADC_WIDTH_BIT_12);
    adc1_config_channel_atten(POTENCIOMETRO, ADC_ATTEN_DB_11);

    configuracao(SERVO_PINO);   // inicializa o servo

    while (1) {
        int leitura = adc1_get_raw(POTENCIOMETRO);
        int graus   = (leitura * 180) / 4095;
        servo_mover(graus);         // move de 0° a 180°
        vTaskDelay(pdMS_TO_TICKS(20));
    }
}

// referência

Funções disponíveis

Função Descrição
configuracao(pino) Inicializa o timer LEDC e o canal PWM para o servo no pino informado.
servo_mover(graus) Move o servo para o ângulo desejado. Aceita valores de 0 a 180°.
configuracao_botao(pino) Configura um pino como entrada com pull-down para uso de botão de reset.

Ligação básica

Alimente o servo com fonte externa de 5V. O GND deve ser compartilhado com o ESP32.

pinout 
┌─────────────────────────────────────┐
│           Servo Motor               │
│  Sinal  →  GPIO 18  (laranja)       │
│  VCC    →  5V externo (vermelho)    │
│  GND    →  GND comum (preto)        │
├─────────────────────────────────────┤
│           Potenciômetro             │
│  Esquerda  →  3.3V                  │
│  Meio      →  GPIO 34 (ADC1_CH6)    │
│  Direita   →  GND                   │
└─────────────────────────────────────┘
